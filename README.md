# 🚦 AI Smart Traffic Control System

## 🚀 Overview
An AI-powered system that predicts traffic congestion, optimizes signal timing, and improves traffic flow using ML, RL, RAG, and multi-agent architecture.

---

## 💡 Features
- Traffic prediction
- Signal optimization
- Reinforcement learning agent
- RAG-based insights
- Streamlit dashboard

---

## ▶️ Run
pip install -r requirements.txt  
streamlit run app.py
